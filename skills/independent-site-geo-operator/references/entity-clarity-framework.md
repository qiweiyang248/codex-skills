# Entity Clarity Framework

AI systems should be able to identify who the brand is, what it sells, who it serves, why it is credible, and how products differ from alternatives.

## Brand Entity

Check:

- Brand name consistency.
- About page clarity.
- Organization schema.
- sameAs links to real profiles.
- Contact details.
- Shipping, returns, warranty, and policy clarity.
- Product category relationship.

## Product Entity

Check:

- Product title and handle.
- Model or SKU.
- Size, color, material.
- Core function and use case.
- Installation or setup method.
- Specs table.
- Price and availability.
- Warranty and support.
- Certifications or standards if real.

## Output

For missing or unclear entity fields, write the exact copy, table field, schema field, or internal link needed to fix it.
