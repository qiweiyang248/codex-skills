# Category Reference: Home, Kitchen, Storage, Decor

Use this reference for furniture, decor, organizers, containers, kitchen tools, bedding, bathroom items, cleaning tools, storage systems, and room products.

## Buyer Questions

- Where does it go in the home?
- How much space does it take or save?
- What does it hold, support, organize, protect, display, or simplify?
- Does the material/finish match the room style?
- How is it assembled, cleaned, stored, or used?

## Required PDP Emphasis

- Scene placement is important: kitchen counter, shelf, drawer, bathroom, desk, living room, bedroom, closet, pantry, laundry room.
- Scale image is usually required.
- Show before/after organization only if realistic and not misleading.
- Show material texture, surface, edges, handles, feet, compartments, lids, fasteners, or joints.

## Claim Rules

Do not invent:

- Exact dimensions
- Load capacity
- Heat resistance
- Dishwasher-safe
- Food-grade
- Waterproof
- Anti-rust
- Solid wood / stainless steel / ceramic / bamboo
- Non-toxic
- Easy assembly time

Use visible materials conservatively unless product data confirms the material.

## Image Sequence Adjustments

1. Main product hero with contents/variants if included.
2. Room/lifestyle/desire image.
3. Buyer task: organize, save space, display, clean, protect, cook, store, decorate.
4. Real-use trust: installed/placed in a real room, hand interaction, drawer/shelf/counter scene.
5. Function: open/close, stack, fold, hang, rotate, assemble, clean, serve, store.
6. Material/detail proof: texture, edge, handle, lid, joint, compartment, coating.
7. Scale/placement: room/furniture/shelf/cabinet/counter/body reference.
8. Specs/package: dimensions, included pieces, care, materials, color variants, assembly notes.
