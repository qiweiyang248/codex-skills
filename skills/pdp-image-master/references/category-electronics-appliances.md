# Category Reference: Electronics, Appliances, Lighting, Smart Devices

Use this reference for products with power, battery, lights, screens, sensors, heating, cooling, motors, charging, smart functions, remotes, or cables.

## Buyer Questions

- What does it do and where does it fit?
- How is it powered, charged, installed, controlled, or operated?
- What devices/rooms/systems is it compatible with?
- What safety, rating, battery, voltage, waterproof, or performance proof is required?
- How big is it in a real room/desk/car/kitchen context?

## Required PDP Emphasis

- Function/how-it-works image is required.
- Scale/placement image is usually required.
- Show controls, ports, screen, indicators, accessories, installation points, or cable path when relevant.
- Use diagrams only when they improve clarity and remain visually premium.

## Claim Rules

Do not invent:

- Battery life
- Charging speed
- Wattage / voltage / amps
- Waterproof rating such as IPX4/IP67
- CE/FCC/UL/RoHS certification
- App compatibility
- Voice assistant compatibility
- Noise level
- Coverage area
- Heating/cooling performance
- Energy savings
- Warranty

Use exact values only when provided.

## Image Sequence Adjustments

1. Main device hero with product shape and interface visible.
2. Lifestyle/room/desk/car/kitchen desire image.
3. Buyer task: simplify routine, save space, automate, light up, clean faster, charge easier, etc.
4. Real-use trust: hand control, installation, placement, cable/port, device in real environment.
5. Function/how-to: controls, modes, charging, assembly, parts, remote/app if supported.
6. Detail proof: material, screen, button, port, motor head, filter, LED, connector.
7. Scale/compatibility: room/device/body/desk/car context, compatible devices if supported.
8. Specs/package: dimensions, power, included accessories, ratings, care, confirmed certification.
