# Category Reference: Tools, Outdoor, Auto, Sports, Pet

Use this reference for repair tools, utility products, camping/outdoor gear, car accessories, bike accessories, sports gear, pet bowls, toys, leashes, harnesses, grooming tools, and active-use products.

## Buyer Questions

- What job does it help complete?
- Is it durable enough for the expected environment?
- Is it compatible with the user's vehicle, gear, pet size, sport, or task?
- How is it installed, used, carried, cleaned, or stored?
- What safety or measurement proof is required?

## Required PDP Emphasis

- Action/use image is important.
- Scale/compatibility image is often required.
- Show grip, attachment, fastener, clip, handle, strap, mounting point, material, edge, surface, or moving part.
- For pet products, show pet size context only when suitable and avoid unsafe scenes.

## Claim Rules

Do not invent:

- Load capacity
- Weatherproof/waterproof/rustproof
- Military grade / heavy duty / professional grade
- Vehicle compatibility
- Pet-safe / non-toxic / chew-proof
- Bite resistance
- UV resistance
- Temperature rating
- Lifetime warranty

Use exact compatibility and measurements only when provided.

## Image Sequence Adjustments

1. Main product hero with accessories/parts visible.
2. Lifestyle/action identity image: workshop, car, camping, sports, pet routine.
3. Buyer task: fix, carry, protect, train, organize, install, travel, outdoor comfort.
4. Real-use trust: hand use, mounted/installed, pet interaction, outdoor/car/workbench scene.
5. Function/how-to: steps, attachments, adjustment, locking, folding, cleaning, storage.
6. Detail proof: material, grip, stitching, buckle, hook, joint, coating, connector.
7. Scale/compatibility: hand, vehicle part, pet size, bike, backpack, toolbench, sport gear.
8. Specs/package: dimensions, included pieces, compatibility, care, confirmed ratings.
