# Category Reference: Beauty and Personal Care

Use this reference for cosmetics, skincare tools, hair tools, nail tools, grooming products, mirrors, razors, brushes, applicators, massagers, hygiene products, and beauty accessories.

## Buyer Questions

- What result or routine moment does it support?
- Is it clean, hygienic, comfortable, and easy to use?
- What skin/hair/body area is it for?
- What is included and how is it used?
- Is the claim safe and supported?

## Required PDP Emphasis

- Show routine context: vanity, bathroom, travel pouch, hand application, hair/nail/skin use.
- Show hygiene and cleaning details when relevant.
- Show texture, applicator, brush head, blade, nozzle, device head, handle, or packaging clearly.
- For devices, also apply electronics rules.

## Claim Rules

Be strict. Do not invent:

- Dermatologist-tested
- Hypoallergenic
- Non-comedogenic
- Medical/clinical results
- Before/after transformation
- Removes wrinkles/acne/scars/hair permanently
- Pain-free
- FDA/CE certification
- Ingredient percentages
- Suitable for all skin types

If user-provided evidence supports a beauty claim, keep wording conservative and exact.

## Image Sequence Adjustments

1. Main product/packaging hero.
2. Lifestyle/routine/vanity desire image.
3. Buyer task: simplify routine, improve application, organize beauty space, travel-ready, etc.
4. Real-use trust: hand holding, bathroom/vanity, application gesture, product texture.
5. Function/how-to: steps, parts, charging if applicable, cleaning, replacement head, dosage.
6. Detail proof: brush fibers, device head, bottle pump, texture, packaging, material.
7. Scale/fit: hand, pouch, shelf, face/body area if appropriate.
8. Specs/package: included items, size, usage notes, care/cleaning, confirmed certifications only.
