# Category Reference: Apparel and Wearable Accessories

Use this reference for clothing, bags, hats, belts, gloves, scarves, shoes, socks, straps, and wearable carry products.

## Buyer Questions

- How does it fit on a real body?
- What style identity does it signal?
- What size, capacity, or body relation should the buyer expect?
- What material, texture, closure, strap, seam, or comfort detail matters?
- Which occasions or outfits does it match?

## Required PDP Emphasis

- Fit/scale image is usually required.
- Use model/body/hand references when possible, while preserving product accuracy.
- Show front/back/side or interior views when relevant.
- Show material texture, stitching, hardware, pocket, zipper, strap, sole, lining, or closure details.

## Claim Rules

Do not invent:

- Fabric composition
- Waterproof/water-resistant
- Genuine leather
- Vegan leather
- Breathable / sweat-wicking / antibacterial
- Compression level
- Fits all sizes
- Load capacity
- Washability

Only use exact size charts, measurements, material names, and care claims when provided.

## Image Sequence Adjustments

1. Main product or model-worn hero.
2. Style/identity/occasion image.
3. Buyer task: daily carry, outfit upgrade, travel, comfort, organization, protection, etc.
4. Real-use trust: worn on body, hand-held, bag opened, walking/sitting/travel scene.
5. Function: pockets, closure, adjustable strap, wear steps, packability, weather use if supported.
6. Material/detail proof: fabric, seams, zipper, buckle, sole, lining, stitching.
7. Fit/scale: model reference, body part, hand, common object, laptop/device if relevant and supported.
8. Specs: size chart, dimensions, color variants, package contents, care instructions.
