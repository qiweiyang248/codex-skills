# 页面示例：观察什么，而不是套什么

打开[对照示例页](visual-examples.html)查看三组示意。全部数字、机构和产品为教学构造，不可用作客户事实；这是信息设计参考，不是可交付PPT模板，也不代表已经通过客户审美确认。

1. 市场比较：左侧用密集表格重复结论，右侧强调同口径规模与进入条件。比较的是信息顺序，不是禁止表格。明细表适合附录。
2. 产品比较：左侧用装饰图标和泛化卖点，右侧按相同维度呈现功能与价格，并区分来源宣称与实测。没有真实素材时，示例保留明确占位，不用假产品图装成事实。
3. 执行安排：左侧以相同卡片堆满动作，右侧显示阶段条件、交付和下一步判断。时间线不是必选；复杂依赖可用流程图或表格。

将自己的页面与示例比较：第一眼能否找到判断？证据是否同口径且易读？图片是否解释产品？哪一条文字删除后不损失信息？整体翻页的重复是否服务于对比？这些问题用于改进，不生成看似客观的审美总分。
