# 证据、比较与估算

用于市场进入、经营复盘及含外部数据/预测的合作提案。先界定研究截止日、市场/平台/品类、时间段和决策问题。公开样本研究不叫“全市场完整抓取”；平台限制、付费墙、登录和不可访问造成的覆盖缺口如实记录。

研究前先审计现有资料：只有能辨认出 `agent-reach` 调研过程，且保留具体来源/平台、可追溯出处、采集时间、当前问题所需主题覆盖并仍具时效时，才可不重复检索；否则使用 `agent-reach` 补充。多来源不是机械覆盖所有平台，而是按决策需要组合官方或一手资料、行业/市场资料、品牌与交易渠道、以及真实用户或社媒讨论。关键判断不得只依赖单一搜索摘要或同源转载。

需要登录产品、销售、广告或平台后台时，向用户说明后台、所需字段及其对结论的影响。验证码、权限不足、登录失败或长时间无响应均应及时报告；不能将未取得的数据写成已验证事实，也不因等待而停止其他独立研究。

## 证据登记与结论追溯

内部证据表按实际需要记录：ID、数据/原文、证据类型、来源机构与直接URL或本地文件页码、发布日期、采集日期、数据期间、国家、平台、主体/品牌/SKU、单位/币种/税、统计口径、样本或估算方法、局限、支持哪条判断。

用户陈述标注“用户确认”；公开网页中的产品宣称标注“卖方宣称”；实际演示/检测才能支持能力实测。资料冲突先核对时期、对象和定义，无法解决则并列解释，不能只留更利于推荐的值。

来源优先考虑与该主张直接相关的一手记录、官方统计、披露报告、品牌/平台页面；第三方测算和评论可补充。来源级别不是充分条件，仍需核对口径、方法和时效。把旧数据明确写为历史数据，不暗示当前售价或当前规则。检索摘要只能作为线索；无法打开原文时标注二手/摘要依据，降低结论强度。

将事实、推断与建议分开。重要结论建立“证据 → 解释及其他可能解释 → 经营影响 → 验证条件”。显示来源短标与关键口径，完整链接/页码置于相关页备注，不自动增加证据或资料来源附录；不能只有无法定位的机构名称。

## 竞品价格与卖点

按国家和相关渠道定义采样范围、日期、关键词和纳入条件。覆盖实际决策所需的价格/功能层级，不把方便获取的几个样本称为市场均价。报告样本数和缺口，不规定通用品类都采相同数量。

逐样本记录品牌、型号、数量/容量/配置、币种、标价与可取得促销价、税运费、优惠条件/会员要求、最低起订量、库存、平台、URL与时间。缺失项目标未知。

同规格、同功能和类似售卖条件优先比较。批发与零售、硬头与软刷、语音设备与OCR扫描笔、音频与摄像眼镜需要分组或明确差异，不用一个低价代表整个品类。功能依据区分卖方宣称、文档支持和实测结果。

有依据时可计算每支/每套价格，不能以除法抹去品质、配置与服务差异。跨币种转换记汇率来源和日期，保留本币；样本小或选择性强时只给观察范围，不给伪精确市场分布。

## 年销售额

依次寻找：明确年度与国家/渠道/SKU范围的披露值 → 定义明确且有时间窗的销量/成交记录 → 可解释的估算。经营实体收入不自动等于所在国家零售额；品牌额不自动分配到单品；平台GMV不等于确认收入，不同渠道还可能重叠。

允许估算但需输入有依据。标为“估算”，列公式、观察窗、价格依据、范围、影响误差的因素及适用边界。

例：已知某SKU连续观察期的销量增量与成交均价，可先计算“观察期成交额≈期间销量×成交均价”。要估全年，还需解释季节性、断货、活动和趋势；只有短期快照时优先交付观察期或年化运行水平，不能称为年度实绩。区间来自输入范围，不随意加减固定百分比。

缺少时间窗的累计sold、评论数、排名、曝光和粉丝不能直接乘价格推全年。依赖排名模型时必须有市场/类目适用性与校准依据。没有可靠方法就保留缺口，提供补数路径；不为表格完整而编造。

不主动加入没有决策作用的机械年化数值：只有单月销量与当前标价、缺少成交均价和季节性依据时，年度栏保留缺口。用户明确要求假设情景时可以另列运行水平，但不能放入年度竞品实绩对比或当作有依据的销售预测。

## 差评与问题

记录采样平台、SKU、时间段、星级/关键词筛选方式、抓取数、去重数与有效样本数。区分主动抽取差评、全星级样本、售后工单和可代表订单总体的数据。

按产品缺陷、使用/兼容问题、宣传预期、履约、包装和售后分类，保留可追溯个案。一个评论可有多个标签，多标签比例可超过100%，需说明。不同来源不能无去重合并。

“问题提及数/所采评论数”只描述该样本；差评样本中的占比不是全部买家的故障率。订单故障/退货率需同周期、同范围订单及售后分母。退款金额率不等于退款订单率，也不等于产品质量缺陷率。

输出：问题证据 → 可能原因（若未证实则标假设）→ 对客户产品的检查/改进建议 → 验证方法。不能将竞品投诉自动归因于客户产品；短期活动或涂色热潮也不自动证明长期需求。

## 经营模型与推荐

对比实际/计划/同期时先统一币种、税、退款、渠道和期间。计划是目标，不能当事实；观察相关变化不直接断言因果，列出缺货、价格、投放等混杂因素。

使用可验证输入和敏感性分析给建议，不以用户偏好替代证据。市场规模与企业进入基础分别评估；推荐附关键成立条件，以及什么新增证据会改变建议。没有完整成本时给待验证的价格或盈亏条件，不推定利润。

地域法规、平台准入、费用与产品资格需用当前适用的一手资料核验，并区分市场开放、跨境卖家资格、具体产品可售三个层次。其他品牌/型号的认证不能代替拟售型号的文件。
