# 页面结构与表达选择

先确定受众需要作出的决定，再安排页面；使用[输入与构思](input-and-concept.md)对应的故事线。服务商优势和合作CTA只在商业合作提案适用，不强制所有模式回答Why Us。

## 正文与附录

正文承载结论、必要证据、取舍与行动。资料来源按[视觉与语言](visual-and-language.md#资料来源的视觉呈现)放在相关页脚与备注，不自动新增来源附录。SKU明细、公式等业务附录仅在用户要求或已确认页序中安排。会议汇报偏重正文，独立阅读可以增加解释。用户明确要求的内容应能查到，不能以“精简”名义丢弃。

页数按内容、演示时长和交付要求确定，不固定比例。对比同一类型对象可复用布局，避免为了多样而破坏可比性；连续重复页面若没有新增判断，应合并或改表达，不能为容纳重复内容自动增加附录。

不默认制作目录页；只有内容规模、阅读方式或用户要求使导航具有实际价值时才加入。

完整制作前必须将逐页计划交给用户评判和调整。逐页计划至少包含：页码、标题或核心判断、主要内容、关键证据/依据、表达形式、页面作用和待确认项；可以用表格或同等清晰的逐页清单。未知结论用准确问题标题，不强行写肯定句。用户明确要求按最佳判断一次完成、免除中间确认或已确认现有逐页方案时可跳过，并在交付中说明关键假设。

## 表达选择

| 页面任务 | 优先表达 | 注意事项 |
|---|---|---|
| 强调一个事实 | 大数字＋对象、时期和单位 | 限定口径靠近数字，不能藏在长备注里 |
| 比较规模/价格 | 条形图、区间图或同规格比较 | 同口径；含促销/税费差异时标注；概念位置不能冒充比例轴 |
| 对比功能与资格 | 精简表格、真实产品图＋差异 | 拆分不等价产品，不用Logo墙代替分析 |
| 解释结构占比 | 条形/堆积图；确有整体时可用环形图 | 部分属于同一总体，显示分母，缺项不能伪装合计100% |
| 解释执行过程 | 时间线、流程与阶段门槛 | 写清进入下一阶段的条件，不只是日历事项 |
| 解释产品使用 | 真实图像＋关键观察 | 标注竞品/示意；图不是销量或质量证据 |
| 展示预算/经营差异 | 原生表格、桥接/对比图 | 明确税、周期、包含项与计算范围 |
| 查阅明细 | 正文表格，或用户要求/已确认的业务附录表格 | 保留表头、单位与来源；过密则拆分，不无限缩小字号 |

## 密度与层级

每页通常承载一个主要问题，支撑点数量取决于证据，不固定3至5条。普通策略正文约120个中文字符是密度预警，不是删掉必要限定语的硬上限；大数字页更少，查阅表格可以更多。先删重复、改图表或拆页，再调整排版。

字号依据[视觉与语言](visual-and-language.md)与实际显示检查。手机预览重点检查结论层级，不声称手机缩略图能读清所有来源；需要细读的来源信息放在对应页备注，默认不增加来源附录。

图表编码、产品图和文字应相互补充。可以在图表旁重述关键数字以方便阅读，但不要用整段重复表格全部内容。
