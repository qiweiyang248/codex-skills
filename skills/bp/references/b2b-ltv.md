# B2B获客与三年客户价值

## 适用条件

仅在当前决策需要客户价值测算且关键输入有依据时使用。不因属于B2B而强制三年预测；短期试验可仅报告线索、商机和首单验证。

本模型是三年累计销售价值，不是无限期生命周期价值，也不是净利润或折现现金流。预计客户数可以是统计期望小数，不代表可以交付小数客户。

## 漏斗定义

按顺序展示并避免混用：

1. 曝光：内容或广告被展示的次数
2. 目标人群触达：符合行业、职位、地区或企业画像的人群覆盖
3. 有效线索：身份可验证、符合ICP、可联系且存在相关需求
4. 合格商机：需求、采购角色、时间或预算达到销售跟进标准
5. 商务动作：RFQ、样品、报价、会议或考察
6. 成交客户：完成首批实际订单的客户
7. 三年客户价值：这批新增客户未来三年预计贡献的累计销售额

在提案中写明每层定义，不把表单数量直接称为有效线索，也不把报价客户直接称为成交客户。

## 基础公式

```text
预计成交客户数 = 有效线索数 × 有效线索成交率
```

```text
第1年销售价值
= 预计成交客户数 ×（平均小批量首单金额
+ 第1年平均复购次数 × 平均复购订单金额）
```

```text
第2年留存客户数 = 第1年成交客户数 × 第2年留存率
第2年销售价值 = 第2年留存客户数 × 年均采购次数 × 平均订单金额
```

```text
第3年留存客户数 = 第2年留存客户数 × 第3年留存率
第3年销售价值 = 第3年留存客户数 × 年均采购次数 × 平均订单金额
```

```text
三年客户价值 = 第1年销售价值 + 第2年销售价值 + 第3年销售价值
单个成交客户三年平均LTV = 三年客户价值 ÷ 第1年成交客户数
```

首批小订单和复购订单必须分开，避免重复计算。

## 必需输入

- 有效线索数量或预计区间
- 有效线索至成交的转化率
- 行业平均小批量首单金额
- 第1年平均复购次数与订单金额
- 第2、3年留存率
- 第2、3年平均采购次数与订单金额
- 币种和是否含税
- 销售周期及客户销售团队跟进能力

数据优先使用客户历史；其次使用客户提供并确认的行业经验；再其次使用可验证的行业资料。其余全部标为模型假设。

## 输出口径

有依据的输入范围可用于保守、基准、进取情景；没有范围依据时展示已知计算和敏感项，不为了三档模型制造精确数字。客户版说明关键假设，不把结果写成保证。

采用完整三年模型时展示相关项：

- 有效线索区间
- 预计成交客户区间
- 首批小订单销售额
- 第1、2、3年预计销售价值
- 单个成交客户三年平均LTV
- 本批新增客户三年累计销售价值

没有可靠毛利率时，只能称为销售价值或销售额，不能称为利润贡献。若有可靠毛利率，可另算三年毛利贡献，但不得与销售额混用。

## 计算脚本

使用 `scripts/calculate_b2b_ltv.py` 计算一个场景。需要多情景且输入具备依据时分别运行。所有费率使用0至1的小数；金额不得为负。

示例：

```powershell
python scripts/calculate_b2b_ltv.py --valid-leads 40 --close-rate 0.1 --small-order-value 50000 --year1-repeat-orders 1 --year1-repeat-order-value 80000 --year2-retention 0.75 --year2-orders 2 --year2-order-value 100000 --year3-retention 0.7 --year3-orders 2 --year3-order-value 110000 --currency CNY
```
