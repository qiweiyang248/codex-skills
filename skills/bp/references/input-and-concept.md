# 输入与构思

## 建立最小项目状态

先从会话和文件提取：受众与决策、当前模式、使用场景、目标地区/周期/语言、已有结论与审批、输出格式、可用素材、保密范围。不要把登记字段变成必须逐项询问用户的问卷。

需要经营判断时，再提取SKU与规格、价格、成本、已有销售/平台/团队/履约基础、约束及目标。仅做视觉重排时保留事实、来源和备注，检查是否有缺页、不可读内容或明显矛盾。

将资料标为：用户陈述、已验证事实、外部数据、客户目标、模型假设、缺口、保密内容。外部与估算证据详见[证据方法](evidence-methods.md)。没有数据不自动放模板数字；可省略非必要项，将影响决策的缺口说明清楚。

## 构思与确认

需要构思时，简述核心问题、比较选项、当前判断及其依据、故事顺序、重要假设；需要商业预算才加入测算，不硬凑固定章节。涉及市场、行业、产品、竞品、消费者或外部商业判断时，先检查现有资料是否保留 `agent-reach` 输出特征、具体平台或来源、链接/出处、采集时间和足以支撑当前决策的主题覆盖；满足时复用，部分满足时增量补充，否则启动公开调研。

- 已有确认：记录确认覆盖的范围并继续，不要求用户重复。
- 信息充分但方向未讨论：可以提出判断并继续准备；是否等待取决于用户的审批要求和结论是否依赖缺失信息。
- 关键歧义：集中提出能改变目标、披露范围、推荐或预算的疑问，解释影响，不用表单阻断独立工作。
- 完成决策主线后，必须先输出完整逐页主要内容供用户评判和调整，再进入视觉与制作；不默认安排目录页。逐页输出至少说明页码、标题/核心判断、主要内容、关键证据或依据、表达形式、页面作用和待确认项。用户明确要求按最佳判断一次完成、免除中间确认或已确认现有逐页方案时才可跳过。代表页确认另按[视觉与语言](visual-and-language.md)执行。

## 不同模式的决策线

| 模式 | 可用组织方式 | 不应默认加入 |
|---|---|---|
| 市场进入研究 | 问题与边界 → 可比证据 → 产品/市场机会与问题 → 条件性推荐 → 验证条件 | 服务商优势、成交话术、无成本依据的销售目标 |
| 商业合作提案 | 客户问题 → 合作价值与证据 → 范围/路径 → 费用/责任 → 结果边界 → 合作决定 | 无关宏观规模、未经授权的案例或保密底价 |
| 经营复盘 | 实际与计划/同期 → 差异拆解 → 原因证据 → 调整动作与责任 → 观察指标 | 把相关性写成因果、以未来预测替换实际差异 |
| 视觉重做 | 内容资产清单 → 信息层级与视觉方向 → 代表页 → 全稿与原内容核对 | 擅改结论/数字、追加市场调研、重复确认商业方向 |

SWOT按需使用：S/W对应当前主体的内部能力与限制，O/T对应外部环境。每点说明证据与经营影响，不为填满四格虚构内容。比较市场优先级时区分市场吸引力与该企业的进入条件；若使用评分，公开权重依据并测试关键权重变化是否改变推荐，不能用打分包装偏好。
