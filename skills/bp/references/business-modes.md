# 业务模式选择

业务模式回答“怎样经营”，汇报模式回答“这次怎样支持决策”。不要把两者混成一套固定页序。仅在选择或解释策略时读取本文件，纯视觉重做不重选业务。

围绕客户、采购/消费场景、价格与利润、内容适配、复购、销售周期、团队、履约和预算判断。通常明确主优先级；只有能支撑目标的辅助渠道才纳入。不硬性限制模块数量，但需解释分工、资源与阶段，不能平均铺开。

| 业务 | 重点判断 | 经营指标示例 |
|---|---|---|
| 香港产品进入内地 | 品牌关系、产品与价格适配、合规履约、种草搜索与店铺承接 | 有效流量、转化、订单、新客、复购、库存周转 |
| 海外电商 | 国家吸引力与企业进入条件分开，平台、本地化、税费、物流售后 | 订单、净销售、获客成本、贡献利润、退款、周转 |
| B2B获客 | 理想客户、采购角色、信任证据、线索筛选、销售移交与跟进周期 | 合格线索、商机、RFQ/样品、首单、回款；长期价值按需 |
| 平台零售 | SKU角色、规格与定价、页面、流量、转化、客服、库存 | 点击/转化、客单价、退款后收入、费用、复购 |
| 品宣与种草 | 主推产品、卖点证据、内容主题、分发与搜索/成交承接 | 目标人群触达、内容表现、品牌搜索、进店、转化 |
| IP获客 | 可信资历、客户需求、专业内容、咨询入口、资格筛选 | 有效咨询、预约、商机、成交贡献，不仅看粉丝 |

指标按当前目标选择并定义分母与周期，不要求每个项目同时展示全部指标。服务提案将动作连接到交付、指标与经营价值；经营研究可以只给验证方案，不需包装服务。

项目经济模型：实际收入中扣除代收税后，再扣相应产品落地成本、平台费、履约、获客、退换货和持续服务成本。按实际账单定义，防止重复扣费。明确“毛利”“订单贡献”“净利润”的不同范围，不把平台费后余额叫利润。预算与费用包含项、税和周期需一致；缺少成本时给盈亏条件或待补项，不给无依据利润保证。

对外展示获准披露的项目成本与贡献利润；服务商保密成本的处理遵循主文件的资料边界。B2B数据不足时先设计短周期线索到商机验证，不能为三年LTV补造留存率。
