# 制作与验收

## 制作衔接

使用主文件指定的可用专业制作技能/工具，读取其实际要求。默认原生文本、表格、图表与关键图形可编辑，图片可替换；不将整页扁平化。不要复制易过时的运行时路径或库API到BP。

制作环境、依赖缺失与文件错误分别处理。校验器报依赖或编码错误不是内容不合格；修复后重跑才能声明通过。无法渲染时说明尚未完成视觉验收，不以文件存在或可解压代替。

## 四项检查

| 检查 | 判定依据 |
|---|---|
| 内容 | 受众能找到本次决策问题的答案，用户要求没有遗漏；模式对应，没有多余销售结构；不确定性与下一步明确 |
| 数据与文字 | 核心结论能追溯证据；数字/图表/正文/备注一致；时间、单位、税、分母、范围正确；事实与估算分开；语言遵循视觉文件 |
| 视觉 | 正常显示下主次明确、证据易读、图像恰当；连续页面的重复有目的；对齐/间距/对比度稳定；决定性限定语可见 |
| 技术 | 最终文件结构正常，编辑性满足要求，字体无意外替代；无溢出、重叠、拉伸或不当裁切；图表轴/标签/数据对应 |

技术检查通过不能证明视觉质量。无数据错误也不能证明商业推荐成立。逐项记录实际检查，不自报没有实施过的“PowerPoint实测”或客户审美通过。

## 最终文件闭环

1. 导出可审阅文件，对全部页面生成最终文件的渲染图或等效预览。仅渲染制作源不能覆盖导出后的变化。
2. 逐页查看，同时回查核心结论、图表和关键数字。查看全页缩略总览，检查重复、色彩和密度变化。
3. 内部记录发现的问题、页码、修改动作和复查证据；没有发现问题也记录检查范围与工具限制，不为留记录制造问题。
4. 修改后重导出、复查受影响页面及跨页一致性；全局字体/布局变更需复查全稿。再次查看总览，确认新最终文件与验收记录对应。

可用简短表：文件版本｜页码/检查范围｜问题｜动作｜复查结果/预览路径。记录放工作目录，不进入客户正文。最终文件变更后不能沿用旧版“通过”记录。

## 交付判断

伪造/错误核心证据、错误币种分母、影响结论的计算错误、不可读正文、明显裁切或不满足要求的编辑性应先修正。未获得的年度数据可以作为清楚标注的研究缺口交付；影响某条建议的缺口需收紧该建议，不能当作纯排版问题忽略。

用户要求先交草稿时标明草稿与未完成项目；不因内部清单自动新增用户审批。正式交付给出实际文件、页数及实质限制，完整来源在文件或配套证据中可查。内部QA、保密资料、空占位和修改聊天记录不混入成品。
