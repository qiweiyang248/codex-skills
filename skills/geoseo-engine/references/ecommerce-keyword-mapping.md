# Ecommerce Keyword Mapping

Map keywords to page types by buyer intent.

## Homepage

- Brand/category broad intent.
- Example: `[brand]`, `[category] store`, `[category] online`.
- Avoid forcing long-tail product keywords into the homepage.

## Product Page

- Product-specific commercial intent.
- Include model, size, material, color, use case, compatibility, or variant.
- Example: `44 inch walnut flush mount ceiling fan with light`.

## Collection Page

- Category and filtered category intent.
- Example: `flush mount ceiling fans`, `modern ceiling fans for bedroom`.
- Collection copy should help shoppers choose, not only describe the category.

## Blog/Guide

- Informational and comparison intent.
- Example: `flush mount vs downrod ceiling fan`, `what size ceiling fan for 12x12 room`.

## FAQ/Support

- Pre-purchase and post-purchase concerns.
- Example: `how to install`, `shipping time`, `returns`, `warranty`, `compatibility`.

## Mapping Output

For each target keyword include:

```csv
keyword,intent,page_type,target_page,current_coverage,recommended_action,priority
```
