# Image SEO Rules

## Filename Rules

- Use lowercase words separated by hyphens.
- Describe product, model, color, size, material, or use case.
- Avoid keyword stuffing and generic filenames like `image1.jpg`.
- Prefer descriptive filenames such as `walnut-flush-mount-ceiling-fan-44-inch-main.webp`.

## Alt Text Rules

- Describe what is visible and useful for the page context.
- Include product type and distinguishing visual attribute when natural.
- Do not repeat the same keyword in every alt text.
- Do not use "image of" unless it helps clarity.
- Keep alt text concise and human-readable.

## Image Role Labels

- Main Image
- Lifestyle Image
- Feature Image
- Spec Image
- Installation Image
- Comparison Image
- Review/User Image

## Output Columns

Use:

```csv
page_url,page_type,image_role,current_image_name,recommended_file_name,current_alt_text,recommended_alt_text,priority,risk_level,verification_method
```
