# Shopify SEO Checklist

Use this checklist for Shopify-first ecommerce SEO audits.

## Technical

- `robots.txt` exists and does not block key product, collection, blog, or page URLs.
- Sitemap exists and is discoverable from `robots.txt`.
- Canonical tags point to the preferred URL.
- Important pages do not contain `noindex`.
- HTTP, HTTPS, www, and non-www variants resolve consistently.
- Product, collection, blog, and policy templates return expected status codes.
- Faceted/filter URLs do not create uncontrolled indexable duplicates.
- Mobile first screen is usable and not blocked by popups.

## On-page

- SEO title exists, is unique, and usually fits 50-65 characters.
- Meta description exists, is unique, and usually fits 140-160 characters.
- One clear H1 exists.
- H2/H3 structure supports search intent and buyer questions.
- URL slug is clear and not stuffed.
- Above-the-fold copy states what is sold, who it is for, and why it is worth buying.
- Internal links connect products, collections, guides, FAQ, and policy pages.

## Ecommerce

- Product page covers model, size, color, material, use case, installation, warranty, shipping/returns, and compatibility where relevant.
- Collection page includes helpful intro copy, buying guidance, related collections, and FAQ where relevant.
- Schema is valid and matches visible page content.
- Product availability and price are accurate.

## Output Rule

Turn every issue into an executable recommendation with Page URL, Page Type, Issue Type, Current Value, Suggested Value, Target Field, Modification Method, Priority, Risk Level, and Verification Method.
